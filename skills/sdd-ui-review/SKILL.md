# sdd-ui-review

## Verificar
- layout/estructura
- componentes
- tokens
- colores/tipografía/spacing
- estados
- responsive
- accessibility
- motion
- contenido/idioma
- reutilización
- inconsistencias visuales
- hardcoded visual values

## Importante
Esta skill no sustituye `sdd-browser-review`.

Resultado por criterio: PASS / FAIL / NOT APPLICABLE, con evidencia del código.
