# sdd-ui — UI/UX Specification

## Propósito
Crear `specs/NNN-slug/ui-spec.md` cuando una funcionalidad tenga impacto visible o interactivo.

## Debe definir
- objetivo de experiencia
- usuarios y roles
- user flows
- pantallas/vistas
- layout y jerarquía
- componentes
- lenguaje visual
- Design System/tokens
- tipografía
- colores
- spacing
- iconografía
- estados: default/loading/empty/success/error/permission/offline/disabled según aplique
- responsive
- accessibility
- motion/transiciones
- idioma/locale/contenido
- referencias/inspiración
- criterios de aceptación UI-001…
- estrategia de browser verification

## Regla
No completar silenciosamente decisiones visuales que el usuario no definió y que puedan cambiar la experiencia. Preguntar o marcar `[NECESITA ACLARACIÓN]`.

## Artefacto
`specs/NNN-slug/ui-spec.md`
